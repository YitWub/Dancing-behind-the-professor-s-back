# BOKAK 2.0 수집 UI 디자인 시스템 · PHASE 4

상태: 통합 워크트리의 첫 실제 디자인. 최종 팀 소유권 계약은 아직 초안이다. 기존 CONTRACT.md와 PHASE 0~3 문서를 교체하지 않는다.

## 컨셉

밝은 캠퍼스 노트에 스티커를 한 장씩 붙이는 경험. ‘대학생활의 모든 발견을 수집하다.’를 화면 전체의 기준으로 삼는다. 사진 중심 식단 목록에서 개인 컬렉션 중심으로 이동한다. 경험은 쌓이지만 메뉴 카드는 하나다. 랭킹·희귀도·사람의 가치 등급·경험치·가짜 완료율은 없다.

## 색·서체·공간

`app/dex/dex.css`의 `.dex-world`에 기존 `--e-*` 변수를 덮어써 `/dex` 영역에서만 적용한다. 원래 홈페이지의 theme.css 및 공통 UI 파일은 수정하지 않았다.

| 역할 | 값 | 적용 |
|---|---|---|
| 종이 | #faf8f2 | 바탕, 작은 점 패턴 |
| 카드 | #fffefb | 카드, 폼, 팝업 |
| 잉크 | #263d33 | 제목·본문 |
| 보조 글 | #66776b | 설명·출처 |
| 캠퍼스 그린 | #2f765b | 주요 버튼, 강조 |
| 버터 | #f4e6ae | NEW, 작은 장식 |
| 라일락 | #e6dff3 | 인연 심볼 |
| 선 | #dedfd3 | 카드 테두리·구분선 |

시스템 글꼴 Arial / Malgun Gothic, 외부 폰트 요청 없음. 큰 제목 28~40px, 일반 카드 제목 12~15px, 보조 정보 10~13px. 화면 가로 너비 1120px 제한. 데스크톱 3열, 작은 화면 2열의 수집 카드. 좁은 화면 카테고리는 세로 목록. 버튼·입력·요약 조작은 최소 높이 44px. 긴 이름은 줄바꿈하고 메뉴명을 잘라 숨기지 않는다. 고정 하단 탐색 막대는 만들지 않았다.

## 카드와 아트워크

- `CollectionCard`: 제목, artwork ReactNode, 선택적인 href / meta / children / locked / isNew. 음식 전용 필드는 필수가 아니다. 카드 전체 링크 안에 추가 버튼·링크를 중첩하지 않는다.
- `CollectionArtwork`: SVG 심볼과 배경·도형·그림자를 조합한다. food / noodles / rice / stew / cutlet / people / custom. children을 전달하면 심볼 영역을 전용 아트로 교체할 수 있다.
- `mealArtwork(name)`: 확실한 한국어 메뉴명 키워드만 사용한다. 불명확하면 food. 저장용 분류·dishId·별칭과 무관한 표시 힌트다. 특정 메뉴의 정확한 그림이라고 주장하지 않는다. 향후 dishId별 전용 아트 매핑은 B/D가 표시 계층에서 연결한다.
- 수집 완료: 색 있는 아트, 실선 프레임, 실제 경험 횟수와 선택 평가, 상세 링크.
- 미수집: 회색·투명 심볼, 점선 프레임, 미수집 표시. 이름은 그대로 공개한다. 클릭해서 수집한 것으로 처리하지 않는다.
- NEW: 화면을 열 때의 시각 기준 firstCollectedAt이 지난 7일 이내인 실제 카드에만 표시한다. 식사 제공일이 아니라 개인 도감 등록 시각이다. 화면이 열린 채 7일을 경과하는 경우 새로 열면 갱신된다. 새로운 발견 애니메이션의 실행 조건과는 별개다.

실제 식판 사진은 카드 메인 아트가 아니다. 제공 식단과 경험 이력의 펼침 영역에서 ‘당시 식판 전체 사진’으로 표시한다. 기존 로컬→원본 URL→사진 없음 처리는 유지한다. 사진이 없어도 카드의 완성도와 수집 기능은 유지된다.

## 정보의 정직성

나의 도감과 오늘의 발견을 구분한다. 기본 진입은 나의 도감이며 `?view=discover`로 식단 탐색에 바로 들어갈 수 있다. 오늘 저장본이 없으면 그대로 안내한다. 현재 저장본의 제공일은 2026-11-04/05이고 최신 수집은 2026-11-04 KST이다.

미수집 예고는 가장 최근의 과거/현재 저장 제공일에서 출처가 확인되고 실제 수집 가능한 selection만 dishId로 중복 제거하여 표시한다. 전체 학교 카탈로그가 아니다. 저장본의 날짜와 오래됨을 표시하고, 이 메뉴를 오늘 제공한다고 말하지 않는다. 전체 목표 개수·진행률은 없다. 인연·자유도감에는 실제 저장 기록 이외의 인물·추억을 넣지 않는다.

## 발견·재방문

`CollectionFeedback`은 Result<CollectResult>를 받는 표현 계층이다. 저장이나 신규 판정을 수행하지 않는다.

| 결과 | 표시 |
|---|---|
| ok + new-entry + !replayed + discovery 있음 | NEW DISCOVERY 모달, 약 0.75초 카드 회전·공개, 약 0.9초 빛 |
| ok + revisit + !replayed | 가벼운 토스트, 실제 조회한 경험 횟수만 팝 애니메이션 |
| replayed | 중복 추가하지 않았다는 알림, 공개·횟수 증가 연출 없음 |
| 실패 | 오류 알림, 성공 카드·증가 연출 없음 |

발견 제목·아트·상세 링크는 도메인에서 전달한다. 저장 후 listExperiences가 성공했을 때만 재방문 횟수를 전달한다. 조회 실패를 추정치로 채우지 않는다. 날짜가 과거여도 ‘그날의 기억’으로 표현한다.

네이티브 dialog.showModal로 배경을 비활성화하고 포커스를 가둔다. 닫기·Escape·계속 둘러보기·상세 이동이 가능하다. 정리 시 기존 조작 요소로 포커스를 복원한다. 건너뛰기는 애니메이션과 빛을 즉시 없앤다. prefers-reduced-motion에서는 애니메이션·빛을 없애고 완성 카드를 바로 보여 준다. 필수 정보·버튼을 애니메이션이 끝날 때까지 숨기지 않는다.
