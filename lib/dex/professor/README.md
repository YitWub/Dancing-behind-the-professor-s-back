# 교수도감

`/dex/professor`에서 공식 명단을 검색한 뒤 실제 수강한 과목·연도·학기를 등록합니다. 공식 명단에 없는 강사·겸임교원은 직접 입력할 수 있습니다. LMS 자동 인증이나 개설 강의 조회 기능은 아닙니다.

## 기록 규칙

- 교수님은 안정적인 professorId로 합치고, 수업은 별도 경험으로 누적합니다. 같은 교수·같은 학기·같은 과목은 중복 저장하지 않습니다. 다른 학기의 재수강은 허용합니다.
- 등록일과 수강 학기를 분리합니다. 등록일을 첫 수업 날짜로 표시하지 않습니다.
- 수강 기록은 수정·삭제할 수 있습니다. 교수 카드 삭제는 모든 관련 수업을 함께 삭제하며 확인을 받습니다.
- 인연도감과 별도 kind를 사용합니다. 교수님의 가치·희귀도·순위를 매기지 않습니다.
- 기존 IndexedDB 트랜잭션·소유권·리비전·요청 재시도 처리를 사용합니다. 기존 학식/인연 기록은 보존합니다. 최초 등록 때 교수도감을 생성합니다.
- 도감 홈의 내보내기/가져오기에서 강의도감과 함께 v16 패키지로 백업됩니다. 기존 v1~v15 백업과 통합 전 교수도감 v11 백업을 계속 읽습니다. 새 교수도감 백업을 복원하려면 v16을 지원하는 앱이 필요합니다.

## 공식 명단과 범위

`data/professors.json`은 공개된 공식 페이지의 이름·소속·출처·확인일만 저장합니다. 이메일·전화번호·사진을 복제하지 않습니다. 공식 명단은 수강 인증이나 현재 강의 개설 여부를 증명하지 않습니다. 일부 학과 및 강사 등이 누락될 수 있어 화면에 부분 명단임을 표시하고 전체 수집률을 제시하지 않습니다.

명단 갱신: `python scripts/sync-professors.py`. Python 표준 라이브러리만 사용합니다. 수집 실패는 unavailableSources에 남기며, 확인된 교수가 한 명도 없으면 기존 파일을 덮어쓰지 않습니다. 소스 페이지 개편 시 파서 결과를 검토해야 합니다.

## 카드 등록 연출

저장에 성공한 CollectResult를 공통 CollectionFeedback에 전달합니다. 처음 등록한 교수님은 학식·인연도감과 같은 카드 등장·빛 반사·건너뛰기·닫기 연출을 사용하며 과목과 학기를 카드에 표시합니다. 기존 교수님의 추가 수업은 기존 카드에 경험이 쌓였다는 알림을 표시합니다. 수정·실패·중복 요청 재전송에는 신규 카드 연출을 띄우지 않습니다. 등록 후 나의 교수님 탭으로 이동하고 검색 조건을 비워 등록한 카드를 바로 볼 수 있습니다.
