# 평가비율 이미지 입력

## 구현과 활성화

승인된 `app/api/grade/assessment-image/route.ts`에서 `assessment-image-server.ts`를
호출한다. 클라이언트는 `assessment-image.ts`의 순수 검증·병합 함수만 사용한다.
서버 모듈을 클라이언트에서 import하지 않는다. Google Gemini의 이미지 입력과 JSON Schema
구조화 출력을 사용하며 외부 SDK·패키지를 추가하지 않았다. 실제 API 요청 코드가 있으며
키가 없을 때 예시 데이터나 가짜 OCR을 반환하는 경로는 없다.

서버 환경변수에 다음을 설정하고 개발 서버를 다시 시작한다. 배포 환경에서도
동일하게 설정한다. 키에 `NEXT_PUBLIC_` 접두사를 붙이지 않는다.

```dotenv
GEMINI_API_KEY=<서버에만 보관하는 Google AI Studio API 키>
GRADE_VISION_MODEL=gemini-3.5-flash-lite
```

기존 2.5 Flash 호출이 404를 반환해, 실제 요청이 성공한 `gemini-3.5-flash-lite`를 사용한다.
설정이 없으면 업로드 버튼을 비활성화하고 수동 입력을 안내한다. `ANTHROPIC_API_KEY`는
이 기능에서 더 이상 사용하지 않는다. Flash-Lite를 선택하려면 모델 값만
`gemini-2.5-flash-lite`로 바꾼다. 기존 2.5 모델과 `gemini-3.5-flash-lite`만 허용하며 다른 모델로 자동 대체하지 않는다. 3.5 모델에는 2.5 전용 `thinkingBudget=0` 옵션을 보내지 않는다.
확인 가능한 배포 설정은 없으므로 운영 인프라·키·예산 설정은 별도로 필요하다.

### 모델 선택과 무료 등급

현재 기본 모델은 `gemini-3.5-flash-lite`다. 기존 2.5 Flash가 실제 요청에서 404를 반환해 변경했다.
개인정보 없는 임시 평가표 이미지로 실제 서버 함수를 호출해 HTTP 200, 평가항목 4개,
반영비율 합계 100%를 확인했다. 이 검증은 개별 평가표의 정확도를 보장하지 않는다.
새 모델에는 기존 2.5 모델용 `thinkingBudget: 0`을 보내지 않는다.

무료 등급은 코드 옵션이 아닌 Google 프로젝트의 사용 등급이다. Google AI Studio에서
해당 모델의 프로젝트 접근 가능 여부·현재 무료 한도를 확인하고, 무료 이용 목적이면
유료 결제를 활성화한 프로젝트 키를 무심코 사용하지 않는다. 앱은 청구 등급을 판별하거나
무료만 사용하도록 공급자 결제를 강제할 수 없다. 유료 프로젝트 키는 과금될 수 있다.
모델 수명·이름 재라우팅·정책은 바뀔 수 있어 운영 시 공식 모델 페이지를 재확인한다.

## 인식·검토·적용

1. PNG/JPEG/WebP, 최대 3MiB의 캡처를 선택한다. PDF·SVG·GIF·HEIC는 지원하지 않는다.
2. 브라우저에서 실제 디코딩·픽셀 수를 확인한다. 2천 픽셀 이내로 축소하고 JPEG로
   다시 인코딩해 메타데이터를 제거한다. 얼굴·이름 등이 있다면 사용자가 표만 잘라 올린다.
3. 외부 Google Gemini 서비스로 전송한다는 안내 후 이미지를 서버로 보낸다.
4. 원래 항목명·비율·상위 항목·확인 필요 여부를 구조화해 추출한다.
5. 결과는 로컬 미리보기에서 수정한다. 이 단계는 과목 초안·자동 저장을 건드리지 않는다.
6. 합계·중복·비율 형식·계층을 검증한 뒤 ‘이대로 적용’을 눌러야 과목 편집에 반영한다.
7. 기존 과목은 기존 자동 저장, 신규 과목은 등록 확인 흐름을 따른다.

비율은 숫자, 0~100%, 전체 합계 100%를 요구한다. 부족하거나 넘쳐도 자동 정규화하지
않는다. 인식 불확실 항목은 명시적 검토가 필요하며 빈 비율은 별도로 수정해야 한다.
세부 항목은 표시하되 적용에서 제외하며, 내부 비율을 전체 비율로 임의 환산하지 않는다.
여러 표·흐린 표·평가표 없음은 재촬영·표 하나만 자르기·수동 입력으로 안내한다.
프롬프트에서 날짜·등급 기준을 제외하고, 분명한 날짜·등급 이름도 검증에서 거부한다.
AI가 의미를 잘못 읽는 경우까지 완벽히 탐지할 수 없으므로 사용자 검토는 필수다.

## 데이터 보호

기존 항목은 정규화한 이름이 하나로 정확히 일치할 때만 연결한다. 알려진 소수의
동의어(중간/midterm 등)만 사용하며 새 이름을 임의로 합치지 않는다. 기존 항목의
ID·점수·과제 그룹·통계·출석 연결을 유지하고 이름·반영비율만 반영한다.
모르는 항목은 원래 이름의 새 단일 평가항목으로 만든다. 과제 개수는 생성하지 않는다.

사진의 항목과 비율을 우선하며 미리보기에는 사진에서 인식한 항목만 표시한다.
사진에 없는 기존 기본 항목(예정 상태이며 과제 기록 없음)은 적용 시 제외한다.
사진에 없는 항목에 점수·채점 대기·0점 확정·이전 미확인 기록 또는 과제 목록이 있으면
기록을 그대로 보존하되 비율을 0%로 바꿔 사진의 합계에 더하지 않는다.
비율 변경은 적용 전 확인하며, 같은 이름으로 연결된 항목은 기존 ID와 기록을 유지한다.
취소·API 실패·네트워크 실패는 원본을 바꾸지 않는다.
기존 점수·과제 구조 변경 확인과 저장 실패 복구는 기존 자동 저장 흐름을 유지한다.

원본 이미지·미리보기는 localStorage에 저장하지 않는다. 서버도 파일·이미지·원문을
영구 저장하거나 로그에 출력하지 않는다. 확정 적용한 평가항목 데이터만 기존 저장
구조에 들어간다. 공급자 측 데이터 처리·보관은 공급자 정책에 따르며 앱이 보장하지 않는다.
무료 등급 요금표에는 입력이 제품 개선에 사용될 수 있다고 표시되어 있다.
따라서 UI에서도 이를 안내하고 개인정보를 제외한 평가표만 업로드하도록 한다.

## 호출 제한·비용·대안

서버는 같은 출처 요청, 본문 크기·MIME·파일 시그니처를 검증하고 공급자 호출에
30초 제한을 둔다. 서버 인스턴스당 분당 최대 10회, 동시 최대 2회로 제한한다.
공급자의 429도 클라이언트에 429와 간단한 무료/사용량 한도 안내로 전달한다.
`Retry-After`가 유효하면 최대 하루 범위로 존중하고, 없으면 60초 동안 같은 서버
인스턴스에서 추가 공급자 호출을 보류한다. 자동 재시도·유료 모델 폴백은 하지 않는다.
이는 기본 남용 방지다. 여러 서버 인스턴스에 걸친 한도·사용자 인증을 대체하지
않으므로 공개 운영 전 배포 계층의 공유 rate limit과 공급자 예산 한도를 검토한다.
정적 export만으로는 사용할 수 없고 Node Route Handler 실행 환경이 필요하다.

비용은 프로젝트의 무료/유료 등급과 모델 정책에 따른다. 이 앱은 요청당 한 이미지,
후보 하나, 출력 최대 4000토큰을 사용하고 thinking budget은 0으로 설정한다.
검색 도구나 파일 업로드·영구 저장 API는 사용하지 않는다. 키는 URL이 아니라
서버 요청의 `x-goog-api-key` 헤더에만 넣으며 클라이언트에 반환하지 않는다.
무료 한도 숫자는 하드코딩해 보장하지 않고 Google AI Studio의 프로젝트 한도를 확인한다.
서버 호출 테스트는 주입한 가짜 공급자 응답으로 수행하며 실제 인식 정확도 측정이 아니다.

브라우저 전용 OCR(Tesseract.js 등)은 외부 이미지 전송 없이 처리할 수 있지만 런타임·
한국어 학습 데이터가 필요하고 표의 항목/숫자 관계·계층 해석을 별도로 구현해야 한다.
이번에는 새 의존성을 추가하지 않고 AI 방식만 구현했으며 OCR 폴백은 구현하지 않았다.

## 출석 연결 보존

AI는 원래 항목명과 비율을 추출하며 주차학습·학습참여도를 출석으로 분류하지 않는다.
설정 탭의 출석 점수 드롭다운을 통해 사용자가 연결한다. 명시적 연결 해제도 유지한다.
수동 연결 ID 또는 이전 확정 출석 스냅샷이 있는 항목은 이미지에 없더라도 0%로 보존하며,
기존 선택을 다른 새 항목으로 임의 교체하지 않는다. 미리보기·취소 중 과목은 변경하지 않는다.
